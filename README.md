# Cinebee
Cinebee is a simple AI-based movie recommendation website with a functional frontend and backend.

To run:
1. Pull the repo, rename `.env.example` to `.env`, and specify the required values.
2. Build and run the backend with `cd backend && npm run build && node .`
3. Build the frontend with `cd frontend %% npm run build`
